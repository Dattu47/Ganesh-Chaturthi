ఉత్సవ గ్యాలరీ & మీడియా నిర్వహణ (1980 → నేటి వరకు)

Supabase ప్రాథమిక స్టోరేజ్ మరియు గిట్‌హబ్ స్టాటిక్ ప్రాజెక్ట్ బ్యాకప్ వ్యవస్థ

🏛️ గ్యాలరీ ప్రాథమిక స్టోరేజ్ & ప్రాజెక్ట్ బ్యాకప్ విధానం (Workflow)

1. Supabase = ప్రాథమిక డైనమిక్ స్టోరేజ్: అడ్మిన్ ప్యానెల్ ద్వారా అప్‌లోడ్ చేసే మీడియా నేరుగా Supabase Storage లో భద్రపరచబడి పబ్లిక్ గ్యాలరీలో కనిపిస్తుంది.
2. ప్రాజెక్ట్/GitHub = స్టాటిక్ బ్యాకప్ సోర్స్: ముఖ్యమైన ఫోటోల కోసం ప్రాజెక్ట్‌లో బ్యాకప్ ఉంచవచ్చు.

స్టాటిక్ బ్యాకప్ ఉంచే సరైన పద్ధతి:
  1. క్రింది ఫారమ్ ద్వారా ఫోటోను అప్‌లోడ్ చేయండి (Supabaseలోకి చేరుతుంది).
  2. "Static Backup Required" ఎంచుకుంటే అదే పేరుతో ఫోటో ఆటోమేటిక్‌గా డౌన్‌లోడ్ అవుతుంది.
  3. మీ ప్రాజెక్ట్‌లో assets/gallery/<year>/ ఫోల్డర్ సృష్టించి (ముందే ఖాళీ ఫోల్డర్లు సృష్టించవద్దు), అందులో ఆ ఫోటోను ఉంచండి.
  4. git add ., git commit -m "Add backup" మరియు git push చేయండి.
  5. హోస్టింగ్ ఆటోమేటిక్‌గా రీడిప్లాయ్ అయి బ్యాకప్ అందుబాటులోకి వస్తుంది.
* గమనిక: బ్రౌజర్ నేరుగా గిట్‌హబ్ లేదా హోస్టింగ్ ఫైల్‌సిస్టమ్‌లోకి రాయలేదు. అందువల్ల ఈ సులభమైన మాన్యువల్ Git వర్క్‌ఫ్లో వర్తిస్తుంది.

శాశ్వత అధికారిక కంటెంట్ (Permanent Static Content)

ℹ️ శాశ్వత పూజా విధానం గమనిక

వినాయక చవితి సంపూర్ణ పూజా విధానం, సంపూర్ణ వ్రతకల్పం, షోడశోపచార పూజ, ఏకవింశతి పత్రపూజ, అష్టోత్తర శతనామావళి, దండకం మరియు శమంతకోపాఖ్యానం శాశ్వతంగా వెబ్‌సైట్‌లో నిక్షిప్తమై ఉన్నాయి. ఇది భక్తుల సౌలభ్యం కొరకు ఎటువంటి మార్పులు లేదా డిలీషన్‌లకు తావులేకుండా స్థిరంగా (Static) ఉంచబడింది. దీనిని అడ్మిన్ ప్యానెల్ ద్వారా సవరించవలసిన అవసరం లేదు.
